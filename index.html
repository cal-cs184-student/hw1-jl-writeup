Task 1: Drawing Single-Color Triangles

To rasterize a triangle, we first compute its bounding box, which is the span of its x and y coordinates. For each point in the bounding box, we check if the pixel is inside the triangle. A pixel is inside the triangle if it is on the inner side of every edge, and this can be determined by performing an edge test on that pixel for every edge. If all edge tests yield the same signedness (to account for clockwise vs. counterclockwise winding order), the pixel is inside the triangle. We fill in all pixels that are considered inside the triangle.

The algorithm is no worse than checking every sample within the bounding box because all operations done on each sample constitute a constant amount of work (three edge tests and a sign check). Therefore, the runtime is still O(area of bounding box).
